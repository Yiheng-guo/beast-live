# 万兽之境

一个因为喜欢而创作的非官方三维现场体验。

体验地址：https://beast.yiheng-guo.com/

可以选择分区与排座、切换观演和手机取景视角、收藏比较位置、选择音乐及舞台风格、仰望点阵天空秀，并浏览作者实拍。
